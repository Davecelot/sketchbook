## Differences and action plan
1. Contract says the tablist role comes from ElementInternals; code writes an attribute (overwriting an author role and aria-orientation). Decide which side is outdated; the attribute is simpler but the contract text should say so, or switch to internals.
2. Default selection only runs when `value` is empty; a `value` that matches no tab, or names a disabled tab, leaves no selected tab and no tab stop reachable by default (Tabs.ts #selectFirst). Fix in code: fall back to the first enabled tab.
3. Late-added panels or tabs leave `aria-controls` stale (same pattern as Collapsible).

Verdict: needs code fix plus a contract wording update.
