Write the specification for a new Switch component: a toggle for an on/off setting that takes part in forms (it submits a value, resets with its form, is disabled by a disabled fieldset, and validates `required`). It is operable by keyboard and accessible, and supports a label, a description, an error message and two sizes.

Produce the specification files in this project, in whatever spec format the project uses, and make them pass the project's own validation if it has any. Do not implement the component code. Do not look for or copy an existing Switch spec.

Nobody is available to approve a plan or answer questions in this session: finish the whole specification yourself, choose the recommended answer for every open question, and record the choice.
