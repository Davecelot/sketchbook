# QA report: out/settings.html

- Line 28: `<sb-switch name="push">` has no `label`, which the Switch contract requires as its visible label and accessible name. The control is announced as an unnamed switch. Fix: add `label="Push notifications"` (use `hide-label` if it must not show).
- Line 27: `tone="success"` is not a Switch attribute (the contract's props are label, hide-label, description, error, size, name, value, checked, required, disabled), so it does nothing. Fix: remove `tone="success"`.
- Line 29: `<sb-toggle>` is not a form field (Toggle contract Q1: it is not form-associated), so `name="digest"` is never submitted with the form. Toggle also has no `label` or `description` props. Fix: replace it with `<sb-switch name="digest" label="Weekly digest" description="A summary every Monday">` (or `sb-checkbox`, see the Save finding below).
- Line 29: the `sb-toggle` has an empty default slot and no `aria-label`, so it renders an empty, unnamed button. Fix: use a switch or checkbox with `label` (as above). If a toggle really is needed, put the text in its slot.
- Lines 27–29 and 31: a settings form that only applies "after you save" goes against the Switch contract ("Don't use a switch for something that needs a Save to take effect; use Checkbox") and the Toggle contract ("Don't use it for a value that waits for a Save button"). Fix: use `sb-checkbox` for these fields, or drop the Save button and the hint so the switches apply at once.
- Line 34: a native `<button class="save">` with hand-written styles (line 15) stands in for the library Button. Fix: use `<sb-button type="submit">Save</sb-button>` and delete the `.save` rule.
- Line 12: `var(--sb-space-17)` does not exist in the token set (the spacing scale stops at `space-16`), so `gap` falls back to 0 and the fields touch. Fix: use a semantic spacing token such as `var(--sb-space-stack-md)` or `var(--sb-space-field-gap)`.
- Line 13: `var(--sb-font-size-small)` does not exist (the tokens are `font-size-sm` and `font-size-caption`), so the hint keeps the inherited size. Fix: use `var(--sb-font-size-sm)`.
- Line 13: the hint color is a hard-coded literal `#d33` instead of a token. It also uses error red for neutral help text and is not covered by the contrast pairs. Fix: `color: var(--sb-color-muted-foreground)`.
- Line 23: `<sb-card-title>` holds plain text, so the page has no heading at all. The Card contract says to put a real heading inside the title when the card belongs in the outline. Fix: `<sb-card-title><h1>Notification settings</h1></sb-card-title>`.
- Lines 7–8: the page loads the stock engine's tokens and bundle from `node_modules/sketchbook/` instead of this design system's own outputs. Brand and token changes made here will not reach the page. Fix: link `../generated/css/tokens.css` and this package's built `dist/` bundle.
