# QA report: out/settings.html

- `<sb-switch name="push" description="Alerts on your phone">` has no `label`, which the Switch contract marks required (accessible name; external labels can't reach the shadow input), so the switch has no accessible name. Fix: add `label="Push notifications"`.
- `<sb-switch ... tone="success">`: Switch has no `tone` prop (contract props: label, hideLabel, description, error, name, value, checked, required, disabled, size), so the attribute does nothing. Fix: remove `tone="success"`.
- `<sb-toggle name="digest" label="Weekly digest" description="...">`: Toggle is a pressed/unpressed button (props: variant, size, pressed, disabled). It has no `name`, `label` or `description`, isn't form-associated, so the digest setting is never submitted and the toggle has no accessible name. Fix: use `<sb-switch name="digest" label="Weekly digest" description="A summary every Monday">`.
- `<button type="submit" class="save">` is a hand-styled native button, not the design system's Button. Fix: use `<sb-button type="submit">Save</sb-button>` and remove the `.save` rule.
- `.fields { gap: var(--sb-space-17) }`: `--sb-space-17` doesn't exist in the token set (the scale has 0–6, 8, 10, 12, 16), so the gap falls back to 0 and the switches touch. Fix: use an existing token such as `var(--sb-space-6)` or `var(--sb-space-stack-md)`.
- `.hint { font-size: var(--sb-font-size-small) }`: `--sb-font-size-small` doesn't exist, so the hint renders at the inherited size. Fix: use `var(--sb-font-size-sm)`.
- `.hint { color: #d33 }` is a hard-coded literal, not a token. Red is also the wrong meaning for neutral help text: it makes the hint look like an error, and its contrast is never checked in `contrast.json`. Fix: use `color: var(--sb-color-muted-foreground)`.
- `<sb-card-title>Notification settings</sb-card-title>` has no heading inside it, and the page has no heading at all. The Card contract says a card has no roles of its own and that you should put a real heading inside `sb-card-title`. Fix: `<sb-card-title><h1>Notification settings</h1></sb-card-title>`.
- The page loads `../node_modules/sketchbook/generated/css/tokens.css` and `../node_modules/sketchbook/dist/sketchbook.js`, which belong to the engine's reference package, not this design system (`ui-a3`). The page won't pick up this project's own brand or components when they change. Fix: link this project's `generated/css/tokens.css` and its built bundle `dist/sketchbook.js` (the `./tokens.css` and `./bundle` exports).
