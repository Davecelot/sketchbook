- `<sb-switch name="push">` has no `label`, which the Switch contract requires as the visible label and accessible name, so the control is unnamed. Fix: add `label="Push notifications"` (or similar).
- `tone="success"` on the Email `sb-switch` is not a Switch prop (the only options are label, hide-label, description, error, size, name, value, checked, required, disabled), so it does nothing. Fix: remove `tone="success"`.
- `<sb-toggle name="digest" label="Weekly digest" description="...">` uses attributes Toggle doesn't have (its props are variant, size, pressed, disabled, and its name comes from slotted text). Toggle is also not a form field, so `digest` is never submitted and the toggle renders with no name. Fix: replace it with `<sb-switch name="digest" label="Weekly digest" description="A summary every Monday">` (or `sb-checkbox`, see the next item).
- The settings only take effect after Save ("Changes apply after you save." plus a submit button), but the Switch and Toggle contracts say not to use them for values that wait for a Save. Fix: use `sb-checkbox` for these fields, or drop the Save button and apply each switch right away.
- The Save control is a hand-styled native `<button class="save">` instead of the design system's Button component. Fix: use `<sb-button type="submit">Save</sb-button>` and delete the `.save` CSS.
- `.fields { gap: var(--sb-space-17) }` uses a token that doesn't exist (the scale jumps from 16 to 10/12/16), so the gap falls back to 0. Fix: use an existing token such as `var(--sb-space-field-gap)` or `var(--sb-space-6)`.
- `.hint` uses `font-size: var(--sb-font-size-small)`, which doesn't exist, so the text inherits the default size. Fix: use `var(--sb-font-size-sm)` (or `--sb-font-size-caption`).
- `.hint` hard-codes `color: #d33` instead of using a token, and red error styling on a neutral help message is misleading and may fail contrast. Fix: use `color: var(--sb-color-muted-foreground)`.
- `<sb-card-title>` holds plain text with no heading element, and the page has no heading at all, so it has no document outline (the Card contract says to put a real heading inside the title). Fix: `<sb-card-title><h1>Notification settings</h1></sb-card-title>`.
