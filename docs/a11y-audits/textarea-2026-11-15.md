# Accessibility audit: Textarea (2026-11-15)

Scope: `spec/components/textarea/contract.json`, `src/components/textarea/*`, `src/mixins/native-control.ts`, `playwright/tests/textarea/*`. Standard: WCAG 2.2 AA and the native multiline `textbox` pattern (native `<textarea>` inside one shadow root with its label, description and error).

## Failures

None open.

### Notes (not failures)

- `NativeControl.describedBy` and `renderDescription` are unused by Textarea (it renders its own `#description`); dead mixin code, no effect.
- Parity item: `label`, `description` and `name` are not declared to reflect in the contract; no accessibility effect because name and description are computed from the shadow-root elements.
