## Failures

None open. No high or medium findings.

### Low (informational, no change required)
- `src/components/badge/Badge.scss:60-95`, 1.4.3: link hover fills use a literal `90%` against `transparent`, so the achieved contrast depends on the page behind the badge. On the default and alternate surfaces measured it holds (lowest 4.52). Fix if the badge is placed on a colored surface: make the hover fill an opaque token (a `bg-hover` pair in the contract, as outline and ghost already have) so T6 can prove it.
- `src/components/badge/Badge.scss:75-80`, 1.4.1: the ghost and link variants carry no affordance at rest beyond text color, so a link badge on its own does not read as a link until hover or focus. Acceptable for a pill that is not inline in body text; keep the meaning in words and use `outline` or `secondary` when discoverability matters.

## Verdict
Verdict: ready
