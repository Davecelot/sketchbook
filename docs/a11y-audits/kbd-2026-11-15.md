# Accessibility audit: Kbd (2026-11-15)

Scope: `spec/components/kbd/contract.json`, `src/components/kbd/*` (`sb-kbd`, `sb-kbd-group`), `playwright/tests/kbd/*`. Standard: WCAG 2.2 AA; no APG pattern (static text, `kbd` has no ARIA role).

## Criteria

| POUR | Criterion | Result | Evidence |
| --- | --- | --- | --- |
| P | 1.4.3 text contrast | Pass | Contract pair `kbd.fg` on `kbd.bg`; computed `rgb(115,115,115)` on `rgb(250,250,250)` (about 4.6:1); `npm run check` T6 passes |
| P | 1.4.11 non-text contrast | Not applicable | Not a control; the key background is decoration, the text carries the meaning |
| P | 1.4.1 color alone | Pass | Key identified by its text, not color |
| P | 1.4.4 / 1.4.12 resize and spacing | Pass | Min-height and min-width, width grows with text; 12px text in a 20px box leaves room for 1.5 line height |
| P | forced-colors | Pass | Probe with `forced-colors: active`: text `rgb(0,0,0)` on Canvas `rgb(255,255,255)` (and inverse in the dark scheme) on default, group, with-icon and in-text; legible. The key chip shape is lost, which does not hide content |
| P | prefers-reduced-motion | Not applicable | No transitions or animation |
| O | 2.1.1 / 2.4.7 / 2.1.2 keyboard, focus, trap | Not applicable | Static; Tab from the default story leaves focus on `BODY`; behavior spec 'is not focusable' passes; no trap |
| O | 2.5.8 target size | Not applicable | Not interactive (contract: "Not interactive") |
| U | 3.2.x predictable, 3.3.x errors, labels | Not applicable | No input, no events |
| R | 4.1.2 role, name, state | Pass | CDP `Accessibility.getFullAXTree`: default exposes only `StaticText: Esc` (no role added); with-icon exposes `image: Shift` from the slotted `svg[role=img][aria-label]` |
| R | Icon-only key has a text alternative | Pass | WithIcon story names the svg; contract tells authors to do so |
| R | ID references across shadow roots | Not applicable | No ID references |
| R | axe | Pass | Behavior spec: axe clean on default, group, with-icon, in-text |
| R | Behavior spec and `npm run check` | Pass | 12/12 passed; all checks pass (A1 warn on spec/api.json is unrelated) |
| R | Screen-reader evidence | Pass | AX tree above plus the `__screen-reader__` snapshots (check S1) |

## Failures

None.

Notes (no criterion fails): `user-select: none` in `Kbd.scss` stops people copying the key text; it is not a WCAG requirement.
