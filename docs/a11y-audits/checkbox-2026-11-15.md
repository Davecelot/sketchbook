## Failures

None open.

### Fixed: form value and validity lagged one microtask after `form.reset()` - was LOW
Location: `src/mixins/form-associated.ts:94,99` (shared mixin; commit c105d6b)
Criterion: `.claude/rules/form-associated-controls.md` (behave like a native `<input>`); not a WCAG criterion.
Before: `FormData` and `validity.valueMissing` read synchronously after `form.reset()` gave `a=on` and `valueMissing=false`; correct only after `await updateComplete`.
After: `formResetCallback` and `formStateRestoreCallback` call `performUpdate()`. Re-probe, synchronous read right after `form.reset()`: `checked=false`, FormData `[b=on]` only, `valueMissing=true`, identical to the async read. `tests/checkbox` 19/19, `npm run check` passes.

### Note: stacked rows and the 24px spacing exception
A single checkbox passes via the spacing exception (box 16px, label 20px high). Lists of checkboxes with row gaps below 4px put box circles within 24px of each other; kits should keep a row gap that holds the exception. Not a component failure.

## Re-audit (2026-11-15, uncommitted working tree): solid invalid focus ring
Change: the focus ring on an invalid control is now solid `destructive` (was a 20% tint), so keyboard focus differs from invalid at rest.
- Invalid at rest, light: border `rgb(231,0,11)`, no ring (shadow is only the 1px elevation). On Tab: border `rgb(231,0,11)` plus a 3px solid `rgb(231,0,11)` ring (4.8:1 on white).
- Dark (`&globals=theme:dark`): rest border `rgb(255,106,91)`; on Tab the same color as a 3px solid ring (7.0:1 on `rgb(10,10,10)`).
- Forced colors: 3px solid `CanvasText` outline on focus; unchanged.
- Reset fix still holds: synchronous read right after `form.reset()` gives `checked=false`, FormData `[b=on]` only, `valueMissing=true`, `checkValidity()=false`.
- `tests/checkbox` (`--workers=2`): 20/20, including the new 'keyboard focus on an invalid control shows a solid ring in the invalid color'.
- `npm run check`: fails only D1/D4 (design-file read-back, Figma round pending, expected); T1-T7 (T5 included), A1, R1, S1 and the rest pass. Not an accessibility finding.
