## Failures

None open.

### Fixed: separator rule invisible in forced-colors mode - was MEDIUM
Location: `src/components/item/Item.scss:60-70` (`:host(sb-item-separator)`)
Before: Group story with `forced-colors: active`: `sb-item-separator` computed `background rgb(255, 255, 255)` (Canvas), 1px, so the rule was invisible.
After: `@media (forced-colors: active) { background: CanvasText; }`; re-probe computes `rgb(0, 0, 0)`, 1px; new spec 'the separator stays visible in forced colors' passes, `tests/item` 23/23.
