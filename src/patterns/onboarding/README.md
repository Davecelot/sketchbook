# Onboarding

First-run screens: a setup step with progress and choices, an empty workspace with next steps, and a setting-up wait state.

## When to use
The first minutes after sign-up, and any empty area that needs to explain what goes there and how to fill it.

## What to replace
- The step question, the roles and the interests.
- The progress value and label ("Step 2 of 3") for each step.
- The empty-state text, its actions and the next-step links.
- The wait text, and how long you show it.

## How to adapt
- Name the progress bar with the step, so the position is read out.
- Use a link for Back (it navigates) and a submit button for Continue.
- A required single choice should be a radio group; the toggle group here can be cleared, which suits an optional pick.
- In the wait state, announce once (the spinner) and hide the placeholders.
